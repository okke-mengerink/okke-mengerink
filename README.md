Sales consultant at SalesWizard and Home Assistant freak, based in the Netherlands.

#### 🏠 Featured project

**[Imou Vacuum for Home Assistant](https://github.com/okke-mengerink/ha-imou-robot)**: adds Imou robot vacuums (tested on the RV-L11-A) to Home Assistant as a standard vacuum entity, with sensors for battery, status, cleaned area and cleaning time. Installs through HACS and uses the official Imou Open Platform cloud API.

[![Open your Home Assistant instance and open a repository inside the Home Assistant Community Store.](https://my.home-assistant.io/badges/hacs_repository.svg)](https://my.home-assistant.io/redirect/hacs_repository/?owner=okke-mengerink&repository=ha-imou-robot&category=integration)

Own an Imou robot? A ⭐ on the repo helps other owners find it.
